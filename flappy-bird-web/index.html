# Flappy Bird 🐦 - Browser Edition A fully playable Flappy Bird clone that runs in your web browser! No installation required. ## How to Play ### Desktop - Press **SPACE** or **ArrowUp** to fly - **ESC** or click anywhere to pause - Avoid the scrolling pipes and keep flying! ### Mobile/Touch Devices - Tap anywhere on the game area to fly - Game responds to touch just like your keyboard controls ## Screenshots

## Game Features ✅ **Simple physics** - gravity pulls you down, tap to fly up ✅ **Smooth gameplay** - optimized for 60 FPS on all devices ✅ **Progressive difficulty** - new pipes appear more frequently as score increases ✅ **High score tracking** - your best score is saved! ✅ **Responsive design** - scales perfectly to any screen size ## Controls | Action | Key/Touch | |--------|-----------| | Fly/Jump | SPACE or Tap | | Pause | ESC or click anywhere | | Restart (after Game Over) | SPACE or Tap again | | Resume from pause | Click anywhere | ## How It Works The game uses the HTML5 Canvas API to render the bird and pipes. Physics are calculated every frame using gravity acceleration (+0.65 per frame) and jump boost (-12 units). The horizontal pipe distance is fixed at 70 pixels. ## Tech Stack - **Frontend:** Vanilla JavaScript (ES6+) - no dependencies! - **Rendering:** HTML5 Canvas - **Style:** CSS3 with flexbox layout ## Docker Deployment This game can be deployed in a containerized environment for testing: ```bash # Build and run docker-compose up --build # Or build image separately docker build -t flappy-bird . # Run your own copy docker run -p 8080:80 flappy-bird ``` Then visit http://localhost:8080 to play! ## Getting Started with Docker 1. Go to your container's IP address or use the provided URL 2. Open http://localhost:8080 in your browser (or https://your-server-ip/ if deployed elsewhere) 3. Start tapping to fly our little bird! 🐦 ## Version Info - **v0.1.0** - Initial release with core mechanics and gameplay loop - Bird movement physics - Pipe collision detection - Score tracking (high score & current) - Touch/keyboard controls - Responsive canvas layout ## Development Notes This is a Proof of Concept implementation. Future versions will include: - Sound effects and ambient music - More bird colors/skins to unlock - Leaderboards for high scores - Multiple difficulty tiers - Customizable physics parameters ## Known Limitations 1. **No audio yet** - game runs without sound currently 2. **Fixed aspect ratio** - maintains 4:3 ratio via CSS 3. **No power-ups** - basic gameplay mode only 4. **Simple graphics** - uses colors and basic shapes for now ## License MIT License - free to use for fun! ---
